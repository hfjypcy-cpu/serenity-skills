## Full report structure

Use this structure for a complete Chinese market scout:

```
研究边界

本次检索截至 YYYY-MM-DD。覆盖市场、主题范围、主要来源类型。说明是否使用实时价格，是否做过逐项估值核验。

方法摘要

用几段话说明本次如何从大趋势拆到瓶颈，再从瓶颈筛到个股。

方向总览

用表格列出主题、需求驱动、瓶颈环节、催化窗口、代表性股票、证据强度。

重点观察名单

用表格列出股票、交易市场、瓶颈角色、为什么可能被低估、关键催化、证据强度、主要风险、下一步核验。

重点个股拆解

对最高质量候选做短文拆解，每只股票写清逻辑链、来源、风险和待验证事项。

不应过度解读的地方

列出证据链薄弱、可能已经 crowded、流动性差、估值已高、稀释较重或时间太早的地方。

覆盖说明

如果研究基于 X、订阅内容、newsletter 或社交语料，说明实际覆盖的栏目、日期、帖子或文章数量、图片/回复/媒体是否完整读取，以及主要缺口。
```

## Theme table schema

Recommended columns:

- 方向
- 需求驱动
- 架构变化
- 关键瓶颈
- 6-24 个月催化
- 可研究标的
- 证据强度
- 当前最大不确定性

## Candidate table schema

Recommended columns:

- 股票 / 市场
- 对应瓶颈
- 低估或错配假设
- 证据等级
- 催化窗口
- 主要风险
- 下一步核验

Keep tables readable. If the candidate list is long, rank the top 10-15 and put the rest in "备选线索".

## Deep-dive schema

For each top candidate, write concise paragraphs plus evidence tables:

1. What the company does and which bottleneck it maps to.
2. What current source evidence supports the chain.
3. Customer map with confirmed, strong-inference, and open-hypothesis labels.
4. Catalyst calendar and expected timing.
5. Why the market might be missing it.
6. What could break the thesis.
7. What must be checked before treating it as actionable.

## Account synthesis schema

When summarizing an investor or analyst account, include:

```
研究覆盖

方法论复原

主题和股票地图

核心案例拆解

持仓/关注/放弃/太早的区分

可迁移的选股流程

证据不足和需要保留的不确定性
```

Do not treat every ticker mention as conviction. Classify stance before drawing conclusions.

## Language rules

Write in natural Chinese. Use tables for dense comparisons. Use paragraphs for reasoning. Avoid vague hype such as "空间巨大" unless followed by the mechanism and source.

Use these labels:

- 已确认
- 强推断
- 早期线索
- 太早
- 暂不进入核心名单

Do not finish with generic invitations for follow-up. End after the report.
